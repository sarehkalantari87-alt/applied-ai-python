# آموزش پایتون - جلسات کلاسی

این مخزن شامل کدهای آموزشی پایتون است که در طول جلسات کلاسی تدریس شده‌اند.

## فهرست جلسات

### جلسه ۱ (`meeting_1_student.py`)
مباحث پایه پایتون شامل:
- تعریف متغیر، مقداردهی و چاپ کردن
- گرفتن ورودی از کاربر (عدد صحیح، اعشاری، رشته)
- نوشتن یک ماشین‌حساب ساده
- عملگرهای `in` و `not in`
- عملگرهای `is` و `is not`
- محاسبه محیط و مساحت دایره
- تبدیل واحد سن (سال به ثانیه، دقیقه، ساعت)
- کار با اعداد مختلط (`complex`)

## نحوه اجرا
```bash
python meeting_1_student.py
```

> توجه: کدهای این فایل به‌صورت کامنت نوشته شده‌اند تا هر بخش جداگانه در کلاس فعال و اجرا شود. برای اجرای هر تمرین، کامنت مربوط به آن را بردارید.
